# XFOIL geometry-edit reference data

Reference results of XFOIL 6.996's airfoil modification commands, used to
validate `aero_geometry::modify`. Every sub-directory with a `case.toml` is
one case: an airfoil (a NACA section generated by XFOIL, or a UIUC
coordinate file) and a list of `[[edits]]`. Each edit runs in its own XFOIL
session (`edit_<name>.in`, transcript `edit_<name>.log`):

- `commands`: `GDES` commands, followed by the answers to their prompts as
  typed in XFOIL (e.g. `FLAP 0.75 999 10` then `0.5`: y = 999 makes XFOIL
  ask for the hinge position as a fraction y/t of the thickness), then
  `EXEC`;
- `interpolate`: `INTE` between the case's file and another file at a
  fraction (0 gives the first airfoil, 1 the second, other values
  extrapolate), then `PCOP`.

The modified airfoil is then written by `SAVE` to `edit_<name>.dat`
(7 significant digits). XFOIL's `EXEC` removes exactly doubled points; the
comparison does the same.

| Case | Edits |
|---|---|
| `naca2412` | flaps down (10° at x = 0.75, y/t = 0.5), up (−15° at 0.7, y = 0), 20° with a high hinge (y/t = 0.8); `TFAC 1.2 0.8`; `HIGH 0.4 0.3`; `TSET` then `FLAP` chained |
| `naca0012` | `TGAP` with two blending distances and splits; `LERA` ×2 and ×0.5 |
| `naca4415` | `TSET 0.13 0.05`; 25° flap at x = 0.8, y/t = 0.3 |
| `clarky` | 12° flap; interpolation (0.3) and extrapolation (1.2) with the Eppler 387 |
| `e387` | `HIGH` of the thickness only; `TGAP` with a lower-surface split |

The polars of a flapped airfoil are in `tests/viscous/naca2412_flap10`.

## Regenerating

```sh
python3 tests/reference/generate.py --xfoil /path/to/xfoil --root tests/geometry
```

or `gh workflow run xfoil-reference.yml -f root=tests/geometry`.
